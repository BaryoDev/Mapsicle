# Security Policy

## Supported versions

Only the latest released version of the Mapsicle packages receives security fixes.

## Reporting a vulnerability

Please do not open a public GitHub issue for security vulnerabilities.

Instead, report it privately via
[GitHub Security Advisories](https://github.com/BaryoDev/Mapsicle/security/advisories/new).

Include a description of the issue, affected package(s) and version(s), and a
reproduction if possible. You should receive a response within a week.
